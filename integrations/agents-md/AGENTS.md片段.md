# 通用接入片段（贴进你的 AGENTS.md / CLAUDE.md / 规则文件）

```markdown
## 输出检查（understd-gate）

写作类输出的目标是"对方懂了"，不是"说完了"。

生成期只记五条：

1. 先定落地句：一句话，读完能复述给别人。
2. 单句不超过 25 字。
3. 术语与数据后面，跟一句人话翻译。
4. 抽象结论后面，跟一个具体场景或类比。
5. 三句连续推理之间，插一句着陆句。

交付前跑检查器（有硬违规退出码为 1，改到 0 再发）：

    python3 ~/.understd/check.py 草稿.md

判"懂没懂"的那关交给冷读者：

    python3 ~/.understd/cold.py 草稿.md --runs 3

落地句写在草稿首行：`【落地句】一句话`。
对话里的回复加 `--lenient`：卡词只提示，只有落点没被抓住才退回。
```
