# understd-gate

**让 AI 写的东西，人真的读得懂。**

> A readability gate for AI-written text: deterministic checks, plus a "cold reader"
> that retells your draft back to you. If it can't, you rewrite it.

---

## 这解决什么问题

AI 写的东西有个稳定的毛病：句子长、术语不解释、结论很抽象、读完记不住一句。
更麻烦的是，**模型自己检查不出来**——它同一个脑子写，同一个脑子判，永远觉得自己写清楚了。

实测过的例子：让模型"用一句很长的中文句子回答"，它能写出一句 740 字、只有一个句号的话。
你让它自己数字数，它数错。

所以这个工具把检查拆成三层，各管各的：

| 层 | 判什么 | 靠什么 | 成本 |
|---|---|---|---|
| 一 | 可数件：句长、术语未翻译、段落过密 | 本地脚本 | 零 |
| 二 | 懂没懂：读者能不能复述出你的落点 | 另起一个干净会话 | 一次模型调用 |
| 三 | 自动跑：写完就查，不用记得 | 平台集成 | 视平台 |

关键是第一条：**能数的规则，不要交给模型判。**

## 快速开始

```bash
git clone https://github.com/oydxxx/understd-gate.git && cd understd-gate
bash install.sh                       # 装到 ~/.understd，并跑一次自检
python3 ~/.understd/check.py 稿子.md   # 查一份稿子
```

或者，把这句话贴给你的智能体，让它自己装：

```
帮我装一个写作检查工具。仓库地址：https://github.com/oydxxx/understd-gate
克隆到 ~/.understd，跑 install.sh，把自检输出贴给我。
```

输出长这样：

```
理解检查 · 失败稿.md
规模：正文 7 块 / 16 句 / 约 293 字

硬违规 · 必须改（3 处）
[U1] 第 2 段第 1 句
    原句：读者读完全文，脑中若没有一个词被重新称过——这篇文，等于没写。
    改法：断成短句：逗号、破折号、顿号处都能断。现在 26 字。

结论：3 处硬违规，改到零再发。
```

退出码：有硬违规是 1，干净是 0。可以直接拿它做循环闸门。

## 冷读者：判"懂没懂"

句长好数，但它只是包装。五十个短句堆一起，读者照样不懂。
所以还有第二层——另起一个**没有上下文**的会话，只给它正文，问三句话：

1. 这段文字讲了什么？
2. 你最可能记住哪一句？
3. 哪一句或哪个词让你读不懂？

再把它的复述，和作者声明的"落地句"对照。对不上就退回。

```bash
python3 ~/.understd/cold.py 稿子.md --runs 3     # 交付物：严格档
python3 ~/.understd/cold.py 回复.md --runs 3 --lenient   # 对话回复：卡词只提示
```

**为什么默认跑三次**：实测同一份稿，两次判定结果相反。单次判定有噪声，取多数。

读稿用哪个模型由你定，默认自动探测本机的 `dsh` / `claude` / `codex`：

```bash
python3 ~/.understd/cold.py 稿子.md --reader-cmd "claude -p"
```

## 规则

规则分两类：能数的交给脚本，判不了的交给人。混在一起是常见的失败来源。

完整表见 [docs/规则说明.md](docs/规则说明.md)。摘要：

- **U1** 单句不超过 25 字（硬）
- **U1b** 连续五句都不到 10 字，像电报（硬）
- **U2** 术语与数据后面跟人话翻译（提示）
- **U2c** 自己加粗或引号标成术语的词，首次出现要解释（提示）
- **U3** 抽象结论后面跟具体场景（提示）
- **U4** 三句连续推理之间插着陆句（提示）
- **U5 / U6 / U0** 紧身衣测试、复述测试、落地句——只能人判，脚本不装懂

豁免：列表、表格、代码块、引用块不按句长判。规范类文档加 `--norm`。

## 三层怎么落地

- **本地 CLI**：`understd/check.py`、`understd/cold.py`。任何能跑命令的智能体都能用。
- **规则片段**：[integrations/agents-md](integrations/agents-md)（通用）、[integrations/claude-code](integrations/claude-code)（含钩子示例）。
- **平台插件**：[integrations/dsh-plugin](integrations/dsh-plugin) 是 DSH 的插件。它每步回复后自动跑检查器，有硬违规就在下一步开头提醒。默认只提醒，不拦人——检查器会误报，硬拦可能把对话卡死。

## 这个工具不做什么

- 不判观点对不对、立场好不好。它只管"有没有人听得懂"。
- 不保证改完就好。它只能指出可数的问题，剩下的是你自己的判断。
- 不做"AI 味检测"那种风格打分。它给的是位置、原句和最小改法。
- 不替你省事：冷读者那层要花模型调用和时间。默认只在交付物上跑。

## 目录

```
understd/            检查器与冷读者（纯 Python，无第三方依赖）
tests/               基础测试：python3 tests/test_check.py
docs/规则说明.md      规则编号、豁免、字数口径
prompts/             给智能体的一句话安装 / 三步安装
integrations/        接入片段与插件
```

## 已知限制

- 提示级规则（U2、U3、U4）会误报。它们是给人看的线索，不是判决。
- 冷读者需要一次模型调用。没有可用命令时它会明确报错，不静默降级。
- 中文规则对英文写作基本无用。要英文版得另写规则表。
- 插件那层绑 DSH。别的平台照 integrations 里的片段接。
