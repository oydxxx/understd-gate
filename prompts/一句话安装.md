# 一句话安装（贴给智能体）

把下面整段复制，粘进你的智能体对话窗口。中途不用管它。

```
帮我装一个写作检查工具。以后我发出去的东西，它要提醒我改。
安装地址：https://github.com/oydxxx/understd-gate
请按四步做完，中途不要问我，只有失败时才停下来问我：
1. 把仓库克隆到 ~/.understd，目录不存在就新建。
2. 按仓库里的 install.sh 装好，跑通一次自带自检。
3. 在你自己这个智能体的规则文件里加一条：交付前先跑 ~/.understd/check.py。
4. 拿一段长句试跑一次，把输出原文贴给我。
做完只回我三句话：装在哪里、以后怎么用、自检结果。
```
